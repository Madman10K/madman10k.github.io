## 3. Data Processing and External Services

As a static website, we do not operate our own database or backend servers to store user accounts or logs. However, when you browse this site, certain technical data is processed through hosting infrastructure and external content providers as described below.

### 3.1 Web Hosting via GitHub Pages
This website is hosted statically using **GitHub Pages**, a service provided by GitHub, Inc. (88 Colin P. Kelly Jr. St, San Francisco, CA 94107, USA), a subsidiary of Microsoft Corporation.

When you access this website, your web browser automatically transmits connection data to GitHub's servers to deliver the requested web pages. GitHub may collect technical server logs, which can include:
- IP address of the accessing device
- Date and time of access
- Requested resource (URL, page, file)
- HTTP status code
- Referrer URL (the previous page from which you arrived)
- Browser type, browser version, and operating system

**Purpose & Legal Basis:** The collection and processing of server log data is technically necessary to deliver the website securely, detect and prevent malicious activities (such as DDoS attacks), and maintain server stability. The legal basis for this processing is **Article 6(1)(f) GDPR** (Legitimate Interest in the secure, reliable, and error-free operation of the website).

For further information regarding how GitHub processes personal data, please review the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

### 3.2 Content Delivery Networks (CDNs) and External Assets
To provide high-quality typography, code syntax highlighting, and cross-platform emoji support, this website loads certain external libraries and assets from trusted third-party providers:

1. **Google Fonts (`fonts.googleapis.com` / `fonts.gstatic.com`):**

   - When loading fonts, your browser establishes a direct connection to Google servers, transmitting your IP address and browser headers to retrieve the font stylesheets and font files.
   - **Legal Basis:** **Article 6(1)(f) GDPR** (Legitimate Interest in uniform, aesthetic, and responsive typography).
   - For more details, see the [Google Privacy Policy](https://policies.google.com/privacy).

2. **Twemoji via jsDelivr CDN (`cdn.jsdelivr.net`):**
   - We use the Twemoji open-source library hosted by jsDelivr (ProspectOne Sp. z o.o., ul. Krowoderska 63B/6, 31-158 Kraków, Poland) to render emojis consistently across different operating systems and browsers.

   - **Legal Basis:** **Article 6(1)(f) GDPR** (Legitimate Interest in consistent multi-platform user interface rendering).
   - For more details, see the [jsDelivr Privacy Policy](https://www.jsdelivr.com/terms/privacy-policy-jsdelivr-net).

3. **Highlight.js via cdnjs / Cloudflare (`cdnjs.cloudflare.com`):**
   - We load the highlight.js syntax highlighting library and stylesheet from cdnjs, powered by Cloudflare, Inc. (101 Townsend St, San Francisco, CA 94107, USA).

   - **Legal Basis:** **Article 6(1)(f) GDPR** (Legitimate Interest in readable and properly formatted code presentation).
   - For more details, see the [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/).

## 5. Your Rights as a Data Subject

Under the GDPR, you have the following statutory rights regarding your personal data:

- **Right of Access (Article 15 GDPR):** You have the right to request confirmation as to whether we process personal data concerning you and, if so, to obtain access to that personal data.
- **Right to Rectification (Article 16 GDPR):** You have the right to request the correction of inaccurate or incomplete personal data.
- **Right to Erasure / "Right to be Forgotten" (Article 17 GDPR):** You have the right to request the deletion of your personal data, subject to statutory retention exceptions.
- **Right to Restriction of Processing (Article 18 GDPR):** You have the right to request the restriction of processing of your personal data under certain conditions.
- **Right to Data Portability (Article 20 GDPR):** You have the right to receive your personal data in a structured, commonly used, and machine-readable format, or have it transmitted to another controller where technically feasible.
- **Right to Object (Article 21 GDPR):** You have the right to object at any time, on grounds relating to your particular situation, to the processing of your personal data based on Article 6(1)(f) GDPR (Legitimate Interests).
- **Right to Withdraw Consent (Article 7(3) GDPR):** If any processing is ever based on your explicit consent, you have the right to withdraw your consent at any time without affecting the lawfulness of processing based on consent before its withdrawal.

To exercise any of these rights, please send an email to [contact@i-use-gentoo-btw.com](mailto:contact@i-use-gentoo-btw.com).
